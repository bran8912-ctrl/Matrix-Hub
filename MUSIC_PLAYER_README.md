# Matrix Hub Music Player

## Quick Access

- **Simple Player**: Available on the [homepage](/) - clean interface, basic controls
- **Advanced Player**: Access at [/player.html](/player.html) - full mixer, layers, playlist features

## Features

### Simple Player (Homepage)
- ▶️ Play/Pause/Previous/Next
- 🔀 Shuffle mode
- 🔁 Loop mode  
- 🔊 Autoplay mode
- 41+ track playlist

### Advanced Player (/player.html)
All simple player features plus:
- 🎚️ **Mixer**: Volume, Pan, Bass, Mid, Treble controls
- 🎵 **Layers**: Play multiple tracks simultaneously
- 📋 **Playlist View**: Visual track list with click-to-play
- 🎨 **Audio-Reactive UI**: Visual effects sync with music
- 💾 **Settings Persistence**: All preferences saved

## Adding New Tracks

1. Place MP3 in `/public/music/`
2. Update playlist in component
3. Add attribution to `music/LICENSE.md`
4. Follow [submission guidelines](music/SUBMIT_MUSIC.md)
